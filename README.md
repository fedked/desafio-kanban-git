# 🚀 Desafio Kanban & Git - Perfil de Desenvolvedor

Este repositório foi criado como um **laboratório prático** para simular o fluxo de trabalho real de uma equipe de TI. O objetivo é testar a organização de tarefas (Kanban), a proteção da branch `main`, o uso de Pull Requests e a integração contínua com Git.

## 📋 Sobre o Projeto
O projeto consiste em um **Card de Perfil (Profile Card)** interativo, contendo:
- Layout moderno com tema escuro e claro (Dark/Light mode).
- Botão de "Seguir" com feedback visual.
- Lista de habilidades (HTML, CSS, JS).
- Estrutura de pastas organizada (`/css` e `/js`).

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estrutura)
- **CSS3** (Estilização, Variáveis de cor e Flexbox)
- **JavaScript** (Manipulação de DOM e lógica de temas)
